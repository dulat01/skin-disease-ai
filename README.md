# Диагностика заболеваний кожи (CAS Model)

Веб-приложение для помощи в диагностике кожных заболеваний с помощью AI. Простой и понятный медицинский интерфейс.

## Возможности

- **Авторизация и регистрация** — вход и создание аккаунта
- **Сброс пароля** — по кнопке «Забыли пароль?» можно задать новый пароль (демо-режим без подтверждения по почте)
- **Загрузка изображения** — выбор фото кожи для анализа
- **Результаты диагностики** — основной диагноз, доброкачественность/злокачественность, топ-3 вероятности
- **История результатов** — просмотр прошлых анализов
- **Настройки** — профиль и информация о приложении

## Запуск

```bash
npm install
npm run dev
```

Откройте в браузере http://localhost:5173.

## Сборка

```bash
npm run build
npm run preview   # просмотр собранной версии
```

Для production нужен отдельный хостинг для `server` (Node.js) и настройка переменных окружения.

## Технологии

- React 18, Vite, React Router
- Локальное хранение пользователей (для демо; в продакшене — backend БД)

**Внимание.** Текущий анализ — имитация для демонстрации интерфейса. Для реальной диагностики необходимо подключить модель (например, ResNet18) через API.
